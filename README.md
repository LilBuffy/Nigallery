### What This Shit Can Do

Nigallery can display images, GIFs, videos, and audio, with search, media type filters, sorting, favorites, hidden files, fullscreen viewing, filmstrip navigation, keyboard controls, mobile swipe navigation, file dimensions and size, video/audio duration, hover autoplay, thumbnail size settings, reduce motion, confirmation settings, and responsive layouts. Basically, media folder mo pero may UI na hindi mukhang Windows Explorer noong 2009.

Favorites and hidden files are saved locally using `localStorage`, so hindi sila napupunta sa GitHub, hindi shared sa ibang visitors, at hindi binabago yung actual files. **Hide ≠ Delete**, kaya hindi mo mabubura buong collection mo dahil lang sa isang fucking button. RUHE, SCHEISSE.

### Tech Stack

**HTML, CSS, Vanilla JavaScript, Node.js, GitHub Actions, and GitHub Pages.**

Node.js is only used as a manifest generator, while GitHub Actions and GitHub Pages handle the automated deployment. Simple stack. Walang 46 dependencies para lang mag display ng fucking image.

### Supported Media

Common image formats such as **JPG, JPEG, PNG, WebP, AVIF, BMP, and SVG**, plus **GIF, MP4, WebM, MOV, OGV, MP3, WAV, M4A, FLAC, and OGG**.

Add your files, regenerate the manifest, and DONE. ПИЗДЕЦ, EZ.
